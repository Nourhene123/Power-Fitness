# Power Fitness — API Reference

Base URL: `/api` (proxied by nginx in the `full` docker-compose profile; `http://localhost:8080/api` in dev).
Auth: JWT bearer (`Authorization: Bearer <accessToken>`), except where noted **public**. Roles: `USER`, `COACH`, `ADMIN`.

All error responses share one shape (`ApiError`, written by `GlobalExceptionHandler`):

```json
{ "timestamp": "...", "status": 404, "code": "RESOURCE_NOT_FOUND", "message": "...", "path": "/api/...", "fieldErrors": [] }
```

## Auth — `/api/auth` (public)

| Method | Path | Description |
|---|---|---|
| POST | `/register` | Create a `USER` account, returns tokens + `UserDto`. |
| POST | `/login` | Returns access + refresh tokens + `UserDto`. |
| POST | `/refresh` | Rotates the refresh token, returns a new pair. |
| POST | `/logout` | Revokes the given refresh token. |
| GET | `/me` | Current user (bearer required) — used for silent-refresh-on-boot. |

## Users — `/api/users`

| Method | Path | Role | Description |
|---|---|---|---|
| PATCH | `/me` | any | Update display name. |

## Coach requests — `/api/coach-requests`, `/api/admin/coach-requests`

| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/api/coach-requests` | public | Contact-form submission (landing page). |
| GET | `/api/admin/coach-requests` | COACH/ADMIN | List, filterable by status. |
| GET | `/api/admin/coach-requests/stats` | COACH/ADMIN | Counts by status. |
| PATCH | `/api/admin/coach-requests/{id}` | COACH/ADMIN | Update status (new/contacted/closed). |
| DELETE | `/api/admin/coach-requests/{id}` | COACH/ADMIN | Remove a request. |

## Assessment — `/api/assessments`

| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/me` | USER | Whether the user has submitted at least one assessment. |
| POST | `` | USER | Submit the 7-step assessment; runs analyzer → roadmap generator → creates/supersedes a `Program` in `IN_REVIEW`. |

## Member program — `/api/me/program`

| Method | Path | Role | Description |
|---|---|---|---|
| GET | `` | USER | Current program summary + `PlanContent` (or `NONE`/`IN_REVIEW`/`CHANGES_REQUESTED`/`ACTIVE`). |
| GET | `/versions` | USER | Version history summaries + changelog. |
| GET | `/versions/{id}` | USER | One version's full detail. |
| GET | `/change-request` | USER | The coach's open change-request, prefilled from the latest assessment. |
| POST | `/change-request/resolve` | USER | Submit answers; version returns to `IN_REVIEW`. |

## Member dashboard & account

| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/api/me/dashboard` | USER | The "7 questions" dashboard view-model (state-dependent shape). |
| GET | `/api/me/account` | USER | Assessment count, for the account page's "re-do assessment" link. |

## Member progress — `/api/me/{workout-sessions,weigh-ins,habits,timeline}`

| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/workout-sessions` | USER | Log a completed session; auto-marks today's `workout` habit. |
| GET | `/workout-sessions` | USER | Last 10 sessions. |
| POST | `/weigh-ins` | USER | Upsert today's weigh-in + measurements (validates 30–300 kg, not future-dated). |
| GET | `/weigh-ins` | USER | Last 20 weigh-ins. |
| POST | `/habits/toggle` | USER | Toggle one of `water\|workout\|nutrition\|sleep` for today. |
| GET | `/timeline` | USER | Merged feed (weigh-ins + workouts + plan review events), newest first. |

## Notifications — `/api/me/notifications` (any authenticated role)

| Method | Path | Description |
|---|---|---|
| GET | `` | Last 30 notifications. |
| GET | `/unread-count` | `{ count }` for the bell badge. |
| POST | `/{id}/read` | Mark one read. |
| POST | `/read-all` | Mark all read. |

## Coach area — `/api/coach/*` (COACH/ADMIN)

| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Stats, pending-review queue, recently-approved, active roster. |
| GET | `/clients/{userId}/profile` | Client profile + latest assessment + analysis + current version. |
| GET | `/clients/{userId}/progress` | 30-day habit matrix + weight log. |
| GET | `/program-versions/{id}` | Plan editor data (version + client profile + safe exercise list). |
| PUT | `/program-versions/{id}` | Save draft edits (rejected once the version is locked). |
| POST | `/program-versions/{id}/approve` | Approve → version `ACTIVE`, prior active version superseded, client notified. |
| POST | `/program-versions/{id}/request-changes` | Ask the client to clarify specific fields. |
| POST | `/programs/{id}/new-version` | Clone the active version into a new editable `DRAFT`. |
